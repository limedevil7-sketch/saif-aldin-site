# Seif — Personal Brand Website

موقع شخصي عصري (Dark + Glassmorphism + Aurora Glow) جاهز للتشغيل مباشرة بدون أي أدوات بناء.

## Project structure

- `index.html` — page structure
- `css/style.css` — styling and animations
- `js/main.js` — personal data and site logic
- `assets/profile.jpg` — profile photo

## Social links

Instagram, Snapchat, Discord and WhatsApp are configured in `js/main.js`.

WhatsApp opens a direct chat using `wa.me` and Discord uses the profile URL generated from the user ID.
